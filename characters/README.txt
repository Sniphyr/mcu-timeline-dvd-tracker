CHARACTER PICTURES GO IN THIS FOLDER

Name each file exactly like the character's id (the id is in js/data-characters.js).
Allowed types: .webp  .jpg  .jpeg  .png   (the .webp below is just an example: any of the four works).
Best shape: a portrait picture about 2:3 (for example 400 x 600 pixels), like the movie posters.
Missing pictures are fine: the page shows a placeholder with the character's name.
You can delete this README.txt file whenever you like.
